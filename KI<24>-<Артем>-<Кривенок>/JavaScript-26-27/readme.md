# Лабораторна робота 1

**Тема:** змінні, оператори, умови та цикли.

## Структура

- `lab1.js` — розв'язки завдань 1–9 (функції повертають результат через `return`, без виводу в консоль).
- `run.js` — виклик функцій з `lab1.js` і вивід результатів у консоль.
- `index.html` — сторінка, яка підключає `lab1.js` і `run.js`.

## Як запустити

Відкрити `index.html` у браузері, натиснути F12 і перейти на вкладку **Console**.

## Завдання

### Завдання 1. Вартість товару — `calculateProductTotalPrice(price, quantity)`
Загальна вартість = ціна × кількість.
Приклад: `calculateProductTotalPrice(250, 3)` → `750`.

### Завдання 2. Секундомір — `convertMsToTimeSpan(totalMs)`
Мілісекунди переводяться в години, хвилини, секунди та мілісекунди за допомогою `Math.floor` і остачі від ділення `%`
(1 с = 1000 мс, 1 хв = 60 000 мс, 1 год = 3 600 000 мс).
Приклад: `convertMsToTimeSpan(3661023)` → `{ hours: 1, minutes: 1, seconds: 1, milliseconds: 23 }`.

### Завдання 3. Знак числа — `getNumberSignStr(number)`
Від'ємне число → `"-"`, інакше → `"+"`.
Приклад: `getNumberSignStr(150)` → `"+"`, `getNumberSignStr(-75)` → `"-"`.

### Завдання 4. Оцінка словом — `getGradeResult(score)`
Спочатку перевіряються некоректні значення (`< 0` або `> 100` → `"#ERR"`), далі діапазони через `else if`:
90–100 → `"excellent"`, 75–89 → `"good"`, 60–74 → `"satisfactory"`, 0–59 → `"unsatisfactory"`.

### Завдання 5. Факторіал — `calculateFactorial(n)`
Добуток чисел від 1 до n у циклі `for`. Edge-cases: `n < 0` → `-1` (факторіал не визначений), `0! = 1`.
Приклад: `calculateFactorial(5)` → `120`.

### Завдання 6. Вартість кошика — `calculateCartTotal(cartItems)`
Цикл `for` проходить по кожному товару і додає `price * quantity` до `total`.
Приклад: `[{ price: 100, quantity: 2 }, { price: 50, quantity: 3 }]` → `350`.

### Завдання 7. Сума чисел від 0 до 666
Усі три варіанти (`for`, `while`, `do while`) повертають **222111**.
`getBeastNumberSum2_AnotherApproach` переписана через `while (true)` з умовою виходу `if (i > beastNumber) break;` всередині циклу.

**Який цикл найзручніше використовувати для цієї задачі? Чому?**
Цикл `for`, бо кількість повторень відома заздалегідь (від 1 до 666), а в одному рядку
записані початкове значення лічильника, умова та крок.

**Чим відрізняється `while` і `do while`?**
`while` спочатку перевіряє умову, тому тіло циклу може не виконатися жодного разу.
`do while` спочатку виконує тіло, а потім перевіряє умову, тому тіло виконається хоча б один раз.

### Завдання 8. Пошук помилки через DevTools — `getDivisibleNumbers(limit, divisor)`
Помилка була в рядку `i + 1;`: значення обчислювалось, але не зберігалось, тому `i` завжди
дорівнювало 1 і цикл був нескінченним (це видно, якщо поставити breakpoint у вкладці Sources).
Виправлено на `i++`.
Приклад: `getDivisibleNumbers(20, 3)` → `[3, 6, 9, 12, 15, 18]`.

### Завдання 9*. Числа з однакових цифр — `getSameDigitNumbers(limit)`
Цикл проходить по числах від 10 до `limit`, кожне число перетворюється в строку, і всі символи порівнюються з першим.
Якщо всі однакові — число додається в `results`. Також додано `const` перед `results`, щоб не створювати глобальну змінну.
Приклад: `getSameDigitNumbers(700)` → `[11, 22, 33, 44, 55, 66, 77, 88, 99, 111, 222, 333, 444, 555, 666]`.
