# Лабораторна робота №3: Об'єкти

**Мета:** закріпити практичні навички роботи з об'єктами в JavaScript:
отримання значень властивостей, формування нових об'єктів, робота
з вкладеними структурами та масивами всередині об'єктів.

## Файли

- `index.html` — підключає JavaScript-файли та дозволяє запустити код у браузері;
- `run.js` — створює тестові об'єкти, викликає функції з `lab3.js` та виводить результати в консоль;
- `lab3.js` — умови завдань та реалізовані функції.

## Запуск

1. Відкрити `index.html` у браузері (Chrome, Edge тощо).
2. Відкрити DevTools (`F12`) і перейти на вкладку **Console**.
3. У консолі відобразяться результати виконання всіх функцій.

`index.html` спочатку підключає `lab3.js`, а потім `run.js`.

## Завдання

| № | Функція | Опис |
|---|---------|------|
| 1 | `validateForm(formData)` | повертає `{ isValid, errors }`, де `errors` — загальний масив усіх знайдених помилок |
| 2 | `validateFormByFields(formData)` | ті самі правила, але `errors` — об'єкт із помилками, згрупованими за полями форми |

## Правила валідації

- `name` — не порожній, щонайменше 2 символи;
- `email` — не порожній, містить символ `@`;
- `age` — від 18 до 150 включно;
- `password` — щонайменше 8 символів;
- `address.country` і `address.city` — не порожні.

Спільні перевірки полів винесено в допоміжну функцію `getFormFieldErrors`,
щоб не дублювати правила валідації в обох функціях.
