# Лабораторна робота: Функції та масиви

**Мета:** закріпити практичні навички роботи з масивами та функціями
в JavaScript, а також навчитися використовувати й аналізувати основні
методи масивів.

## Файли

- `index.html` — підключає JavaScript-файли та дозволяє запустити код у браузері;
- `run.js` — викликає функції з `lab1.js` та виводить результати їх виконання в консоль;
- `lab1.js` — умови завдань та реалізовані функції.

## Запуск

1. Відкрити `index.html` у браузері (Chrome, Edge тощо).
2. Відкрити DevTools (`F12`) і перейти на вкладку **Console**.
3. У консолі відобразяться результати виконання всіх функцій.

`index.html` спочатку підключає `lab1.js`, а потім `run.js`.

## Завдання

| № | Функція | Опис |
|---|---------|------|
| 0 | `containsBirthDay(numbers, birthDay)` | перевіряє, чи містить масив число — день народження |
| 1 | `myIndexOf(array, value)` | власний аналог методу `indexOf()` |
| 2 | `myFilter(array, predicate)` | власний аналог методу `filter()` |
| 3 | `getShiftAndPopResult()` | аналіз роботи методів `shift()` і `pop()` (код готовий, пояснення — у коментарях `lab1.js`) |
| 4 | `getNonCommonElements(first, second)` | елементи, які присутні лише в одному з двох масивів |

## Пояснення до завдання 3

- `first` = `10` — `shift()` видаляє перший елемент масиву та повертає його;
- `last` = `50` — `pop()` видаляє останній елемент масиву та повертає його;
- `numbers` = `[20, 30, 40]` — масив без першого та останнього елементів;
- обидва методи **змінюють початковий масив**, а не створюють новий.
